SQL:

Pandas:

df["Age"] > 25

creates a Boolean Series:

True
False
True
False

Then:

df[condition]

keeps only rows where condition is True.

7. Multiple Conditions
AND

Use:

&

Example:

df[
    (df["Age"] >= 28) &
    (df["Salary"] < 70000)
]
Important

Always use parentheses around each condition:

(df["Age"] >= 28) & (df["Salary"] < 70000)

Not:

df["Age"] >= 28 & df["Salary"] < 70000
OR

Use:

|

Example:

df[
    (df["City"] == "Delhi") |
    (df["Salary"] >= 60000)
]
Why & and |?

Pandas conditions operate on multiple values/Series.

Think:

Age column → True False True False
Salary     → False True True False

& combines corresponding Boolean values.

8. .loc

.loc is mainly label-based selection.

General structure:

df.loc[rows, columns]

Example:

df.loc[df["Salary"] >= 50000, ["Name", "City"]]

Meaning:

Select rows where Salary ≥ 50000 and return Name and City.

.loc for modifying data

This is extremely important.

df.loc[df["Age"] < 25, "Age_Group"] = "Young"

Meaning:

Find rows where Age < 25 and put "Young" into Age_Group.

Another example:

mask = df["Salary"].isna()

df.loc[mask, "Salary"] = 50000
9. .iloc

.iloc is integer-position based.

df.iloc[0]

First row.

df.iloc[0:5]

Rows at positions 0–4.

df.iloc[0:5, 0:3]

First 5 rows and first 3 columns.

Mental rule:

loc  → labels
iloc → integer positions

13. columns vs subset

Very important distinction.

columns=

The columns themselves are the target.

Example:

df.drop(columns=["Age", "Salary"])

Means:

Delete these columns.

subset=

Only these columns are considered/check­ed for an operation.

Example:

df.dropna(subset=["Age", "Salary"])

Means:

Check Age and Salary when deciding which rows to drop.

It does NOT delete those columns.

Example:

df.drop_duplicates(subset=["Name"])

Means:

Check Name when deciding whether rows are duplicates.

Mental rule:

columns → act on the columns

subset → use these columns for the decision

15. Manual Missing-Value Filling

This was one of the most important concepts we practiced.

mask = df["Salary"].isna()

df.loc[mask, "Salary"] = 50000

Mental process:

1. Find missing rows
2. Create mask
3. Use .loc
4. Replace only those cells
16. Filling With Median

Median is often safer than mean when there are outliers.

median = df["Salary"].median()

mask = df["Salary"].isna()

df.loc[mask, "Salary"] = median

Why median?

Example:

40000
45000
50000
50000
1000000 ← outlier

Mean gets pulled upward.

Median is more resistant to outliers.

17. Category Missing Values

For categorical data, mode is often useful.

df["City"].mode()[0]

Then:

df["City"] = df["City"].fillna(df["City"].mode()[0])

General thinking:

Numerical → mean / median

Categorical → mode

But the correct choice depends on the dataset.

18. combine_first()

Used when you want to fill missing values in one column using another column.

Example:

df["col1"] = df["col1"].combine_first(df["col2"])

Meaning:

Use col1 if value exists.
Otherwise use col2.

This is similar to:

"Take the first available value."

Manual .loc approach:

mask = df["col1"].isna()

df.loc[mask, "col1"] = df.loc[mask, "col2"]

Both approaches can solve the problem.

19. dropna()

Drop rows containing missing values:

df.dropna()

Only consider certain columns:

df.dropna(subset=["Age", "Salary"])
how="all"
df.dropna(
    subset=["Age", "Salary"],
    how="all"
)

Drop the row only if both Age and Salary are missing.

Example:

A → Age exists, Salary missing → KEEP
B → Age missing, Salary exists → KEEP
C → both missing → DROP
D → both exist → KEEP
how="any"
df.dropna(
    subset=["Age", "Salary"],
    how="any"
)

Drop the row if even one is missing.

25. transform()

This was an important concept.

groupby().mean() returns one result per group.

df.groupby("Department")["Salary"].mean()

Example:

IT       60000
Sales    55000
HR       50000

But:

df.groupby("Department")["Salary"].transform("mean")

returns one value for every original row.

Example:

Employee       Department    Department Mean

Amit           IT            60000
John           IT            60000
Sara           Sales         55000
Riya           Sales         55000

Mental rule:

groupby().mean()
    ↓
one result per group

groupby().transform("mean")
    ↓
same length as original DataFrame
26. Group-Wise Missing Value Filling

Suppose missing salaries should use the average salary of that employee's department.

First:

group_mean = (
    df.groupby("Department")["Salary"]
      .transform("mean")
)

Now:

mask = df["Salary"].isna()

df.loc[mask, "Salary"] = group_mean[mask]

Why group_mean[mask]?

Because group_mean is a full Series with one value per row.

group_mean → many values → can use [mask]

median → one number → don't use [mask]
27. map()

Used for simple value → value mapping.

df["Gender_Code"] = df["Gender"].map({
    "Male": 1,
    "Female": 0
})

Mental model:

Take each value
      ↓
Look it up
      ↓
Replace it

Example:

Male   → 1
Female → 0

Values must match exactly.

"Male" ≠ "male"
"Large" ≠ "Large "

Unmatched values generally become NaN.

44. Feature Engineering Connection

Feature engineering means:

Creating useful new features from existing data to help a Machine Learning model.

Examples:

df["Bonus"] = df["Salary"] * 0.10
df["Age_Group"] = ...
df["Salary_vs_Department_Avg"] = (
    df["Salary"]
    -
    df.groupby("Department")["Salary"].transform("mean")
)

Date feature:

df["Joining_Year"] = df["Joining_Date"].dt.year

String feature:

df["First_Name"] = df["Name"].str.split().str[0]

The important point:

Feature engineering is not just learning more Pandas functions. It is deciding what useful information can be extracted from the data.

45. Most Important Mental Patterns

These are worth remembering.

Pattern 1 — Filter
df[condition]
Pattern 2 — Modify selected rows
df.loc[condition, "column"] = value
Pattern 3 — Group and calculate
df.groupby("column")["value"].mean()
Pattern 4 — Group and calculate multiple things
df.groupby("column").agg(...)
Pattern 5 — Group and broadcast result
df.groupby("column")["value"].transform("mean")
Pattern 6 — Map values
df["new"] = df["old"].map({...})

df["new"] = df["old"].apply(function)
Pattern 8 — Clean strings
df["Name"] = df["Name"].str.strip().str.title()
Pattern 9 — Join tables
df1.merge(
    df2,

46. Common Beginner Mistakes We Encountered
❌ Forgetting parentheses around conditions

Wrong:

df["Age"] > 25 & df["Salary"] < 50000

Correct:

(df["Age"] > 25) & (df["Salary"] < 50000)
❌ Using and / or

Don't use:

df["Age"] > 25 and df["Salary"] > 50000

Use:

(df["Age"] > 25) & (df["Salary"] > 50000)
❌ Confusing .str and .str()

Wrong:

df["Name"].str().strip()

Correct:

df["Name"].str.strip()
❌ Forgetting that strings are case-sensitive
"Small" != "small"

Clean first if necessary:

df["Size"] = (
    df["Size"]
    .str.strip()
    .str.title()
)
❌ Treating a scalar like a Series

This is wrong:

median[mask]

if:

median = df["Age"].median()

because median is one number.

Correct:

df.loc[mask, "Age"] = median

But this can work:

group_mean[mask]

because transform() returns a Series with one value per row.

❌ Accidentally overwriting original data

Instead of:

df["Salary"] = df["Salary"].apply(salary_label)

often better:

df["Salary_Label"] = df["Salary"].apply(salary_label)

unless you actually want to replace Salary.

❌ Forgetting quotes around column names

Wrong:

df[size]

Correct:

df["Size"]
❌ Mixing assignment and display

Keep operations separate:

df["Year"] = df["Date"].dt.year
df.dtypes
df
